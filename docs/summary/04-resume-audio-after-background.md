# 04 · เสียงหายหลังปิดจอหรือสลับแอป

## ปัญหา
ใช้งานอยู่แล้วได้ยินเสียงปกติ แต่พอปิดจอแล้วเปิดใหม่ หรือสลับไปแอปอื่นแล้วกลับมา จะไม่มีเสียงอีกเลย

## สาเหตุ
- iOS จะพัก AudioContext (`suspended` หรือ `interrupted`) เมื่อปิดจอ สลับแอป หรือมีสายเข้า และจะไม่กลับมาทำงานเอง
- โค้ดเดิมจำไว้ว่า "ปลดล็อกแล้ว" ตั้งแต่แตะครั้งแรก จึงไม่เคยสั่ง resume อีก
- ตัวฟังการแตะหน้าจอ (`AudioUnlock`) ถูกถอดออกหลังปลดล็อกครั้งแรก การแตะครั้งต่อไปจึงไม่ได้ปลุกเสียง

## แก้อะไร
- `lib/audio.ts`
  - ใช้สถานะจริงของ context (`isAudioRunning()`) แทนตัวแปรที่จำไว้ครั้งเดียว
  - ฟัง `statechange` ของ context: ถ้าถูกพัก ให้กลับไปสถานะ `locked` (ขึ้นป้าย "แตะที่ใดก็ได้เพื่อเปิดเสียง")
  - กลับมาที่แอป (`visibilitychange`, `pageshow`, `focus`) จะลอง resume ให้เอง
  - ก่อนเล่นเสียงทุกครั้ง ถ้า context ไม่ทำงาน จะปลุกให้ทันทีใน gesture เดียวกัน และรอ resume ไม่เกิน 400 ms (กันค้าง)
  - เล่นไฟล์เสียงเงียบซ้ำทุกครั้งที่ปลุก เพื่อให้ iOS คืนช่องเสียงสื่อ (ดังแม้เปิดโหมดเงียบ)
- `components/AudioUnlock.tsx`: ฟังการแตะตลอดการใช้งาน ไม่ถอดออก

## ตรวจแล้ว (Edge, จำลองการพักเสียงแบบ iOS)
- พักเสียง → ขึ้นป้าย "แตะที่ใดก็ได้เพื่อเปิดเสียง"
- กด "ฟังอีกครั้ง" → context กลับเป็น running และเล่นเสียงได้
- พักอีกครั้งแล้วแตะที่ว่าง → กลับมาทำงาน, ตอบข้อต่อไปมีเสียงตามปกติ
- ทดสอบซ้ำทั้งเส้นทางหลัก: ปลดล็อกเสียง, ไมค์, ปลดล็อก E ที่ข้อ 30, รีโหลด, ออฟไลน์ และการจำลองไมค์บน iOS ผ่านทั้งหมด
- ยังไม่ได้ทดสอบบน iPhone จริง
