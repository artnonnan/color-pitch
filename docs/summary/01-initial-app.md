# 01 · สร้างแอป Color Pitch ครั้งแรก

## ทำอะไรไป
- สร้างเว็บแอป Next.js 16 + TypeScript + Tailwind สำหรับฝึก absolute pitch คู่กับการจับคู่เสียงกับสี
- แบบฝึก 5 แบบ: โน้ตแรกของวัน (ไมค์/แถบเลือกเสียง), ทายโน้ต+สี (ปลดล็อกตามความแม่นยำ ≥90% ใน 30 ข้อ), สีและอารมณ์ของคอร์ด, ความสว่างของโหมด (สัปดาห์ 4), จูนเนอร์พกพา
- หน้าแรก: เช็กลิสต์วันนี้ + ปุ่มเริ่มฝึกต่อเนื่อง, streak, โน้ตที่ปลดล็อก, หลักสูตร 4 สัปดาห์
- หน้าสถิติ (กราฟ SVG), หน้าตั้งค่า (สี, เครื่องดนตรี, ช่วงอ็อกเทฟ, ธีม, ส่งออก/นำเข้า JSON, ล้างข้อมูล)
- PWA: manifest, ไอคอน, service worker ใช้งานออฟไลน์ได้ (รวมเสียงเปียโน)
- ข้อความ UI ทั้งหมดอยู่ใน `i18n/th.ts`

## ตรวจสอบแล้ว (Edge headless จอ 375px)
- `npm run build` ผ่าน ไม่มี error
- เสียง: ก่อนแตะ context = suspended, หลังแตะครั้งแรก = running และโหลดเปียโนครบ 20 ไฟล์
- ไมค์ (ป้อนคลื่น C4 ปลอม): วัดได้ห่าง 0.03 เซนต์, จูนเนอร์ตอบ C ถูก
- ไมค์ถูกปฏิเสธ: แสดงข้อความและสลับเป็นแถบเลือกเสียง บันทึกผลได้
- ตอบ 33 ข้อ (ผิด 2) ปลดล็อก E ที่ข้อ 30, ครบ 3 ขั้นของวัน
- รีโหลดแล้วความคืบหน้ายังอยู่, ออฟไลน์แล้วเปิดแอปได้

## ยังไม่ได้ตรวจ
- iOS Safari บนเครื่องจริง (ทำตามแนวทางปลดล็อกเสียงของ iOS แล้ว แต่ต้องทดสอบบน iPhone)

## เจอและแก้ระหว่างทาง
- คีย์ดำกว้างเกิน ทำให้แตะกลางคีย์ขาว G แล้วโดนคีย์ดำที่ล็อกอยู่ → ลดความกว้าง และให้คีย์ดำที่ล็อกปล่อยการแตะผ่านไปคีย์ขาว
- Tailwind 4.3 ต้องใช้ Node ≥ 20.19 เครื่องนี้เป็น 20.14 → ใช้ 4.2.4
