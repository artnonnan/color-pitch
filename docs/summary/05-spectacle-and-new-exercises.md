# 05 · เพิ่มความอลังการ + แบบฝึกใหม่ 3 แบบ

## ความอลังการ (`components/fx/`)
- **อนุภาคสีระเบิด** (`Burst.tsx`): canvas เต็มจอ ยิงอนุภาคเป็นสีของโน้ตจากคีย์ที่ตอบถูก ยิ่งคอมโบสูงยิ่งแรง
- **คอมโบ**: ตอบถูกติดกันตั้งแต่ 3 ข้อขึ้นไปจะขึ้นป้าย 🔥 ครบทุก 10 คอมโบมีพลุ
  - ป้ายคอมโบใช้สีคงที่ เพราะถ้าใช้สีของโน้ตปัจจุบันจะบอกใบ้คำตอบ
- **พิธีปลดล็อกโน้ตใหม่** (`Celebration.tsx`): เต็มจอ มีวงแหวนกระจาย ลูกแก้วสีใหม่ พลุ และเสียงโน้ตใหม่ แตะเพื่อไปต่อ
- **ออโรร่า** (`Aurora.tsx`): แสงเบลอเคลื่อนช้าๆ หลังแอป ใช้สีของโน้ตที่ปลดล็อกแล้ว
- **พลุ** ตอนฝึกครบวัน ตอนได้สถิติใหม่ใน Color Rush และตอนปลดล็อกคอร์ดใหม่
- ปิดเอฟเฟกต์ทั้งหมดเมื่อเครื่องตั้งค่า "ลดการเคลื่อนไหว" และล้างอนุภาคทุกครั้งที่เปลี่ยนหน้า

## แบบฝึกใหม่
| แบบฝึก | ไฟล์ | ทำอะไร |
|---|---|---|
| Color Rush | `exercises/Rush.tsx` | 60 วินาที ตอบให้มากที่สุด ตัวคูณคอมโบสูงสุด x5 ตอบเร็วได้โบนัส บันทึกสถิติสูงสุด คำตอบนับรวมเพื่อปลดล็อกโน้ต |
| ร้องตามสี | `exercises/Sing.tsx` | เห็นแค่สี (ไม่บอกชื่อ) แล้วร้องเสียงของสีนั้น ห่างไม่เกิน ±50 เซนต์นับว่าถูก ถ้าใช้ไมค์ไม่ได้ให้แตะคีย์ไม่มีสีแทน |
| รากของคอร์ด | `exercises/Roots.tsx` | ฟังคอร์ด แล้วแตะโน้ตราก ถ้าตอบผิดจะเล่นโน้ตรากให้ฟังแล้วตามด้วยคอร์ด |

- ทุกแบบฝึกใหม่ต้องทำโน้ตแรกของวันก่อน (หรือกดข้าม) เหมือนแบบฝึกอื่น
- เพิ่มการ์ดในหน้าแรก และเพิ่มสถิติ 3 ช่องในหน้าสถิติ
- state ใหม่: `progress.rush`, `progress.sing`, `progress.roots` (ไฟล์สำรองเก่ายังนำเข้าได้ ค่าที่ไม่มีจะเป็นค่าว่าง)

## ตรวจแล้ว (Edge headless 375px)
- Color Rush: ตอบ 160 ข้อใน 60 วินาที บันทึกผล ขึ้น "สถิติใหม่!" และพิธีปลดล็อกทำงานหลังจบรอบ
- ร้องตามสี (ไมค์ปลอมร้อง C): บันทึก 8 ข้อ ข้อที่เป้าเป็น C ได้ 0 เซนต์และขึ้น "เป๊ะมาก!"
- รากของคอร์ด: 10 ข้อ ถูก 9 (ตั้งใจตอบผิด 1 ข้อ) แสดงสรุปถูกต้อง
- ทดสอบซ้ำเส้นทางเดิมทั้งหมด: ปลดล็อกเสียง, ไมค์, พิธีปลดล็อก E ที่ข้อ 30, รีโหลด, ออฟไลน์, ไมค์ถูกปฏิเสธ, เสียงกลับมาหลังพักเสียง, การจำลองไมค์บน iOS ผ่านทั้งหมด ไม่มี error

## เจอและแก้ระหว่างทาง
- ตัวคูณคอมโบไม่มีเพดาน (บอทได้ x32) → จำกัดไว้ที่ x5
- พิธีปลดล็อกโปร่งใสจนเห็นแต้มข้างหลัง → ใช้พื้นทึบ
- ระยะห่างตัวอักษรทำให้คำไทยแตก ("ป ล ด ล็ อ ก") → เอาออก
- พลุจากหน้าก่อนลอยค้างในหน้าใหม่ → ล้างอนุภาคเมื่อเปลี่ยนหน้า
