## ที่เพิ่ม

- จำลองเป็น iPhone หน้าจอ 375px ที่แตะด้วยนิ้ว
- ใช้โปรไฟล์ใหม่ทุกครั้ง จึงเหมือนผู้เล่นใหม่ทุกรอบ

  - ฟีเจอร์อื่นที่ยังไม่ได้ทำ map มีรายชื่ออยู่ใน README ของ map
- `recipes/`: สคริปต์ขับของแต่ละฟีเจอร์ ใช้ทางเดียวกับผู้เล่นเท่านั้น (แตะ รอ แตะข้ามเฉลย) ไม่เขียน state ตรงๆ

**README:** เพิ่มบทเรียนใหม่ในตาราง และเพิ่มหัวข้อ Verification

## ปัญหาที่เจอและแก้

**`puppeteer.launch` เปิด Edge 156 ไม่ได้**
- launch ปกติล้มเหลวโดยไม่มี error ส่วนโหมด pipe ขึ้น "Target closed"
- แก้โดยให้สคริปต์เปิด Edge เองบนพอร์ตว่าง แล้วใช้ `puppeteer.connect`
- แก้ template ใน `D:\Engine\featuremap\harness\web\drive.cjs` ด้วย ทดสอบแล้วผ่าน และบันทึกลง `FOR_CLAUDE.md`

**ลบโปรไฟล์ไม่ได้หลังปิด Edge**
- process ลูกของ Edge (crashpad) ยังเปิดไฟล์ในโปรไฟล์ค้างไว้
- แก้โดยใช้ `taskkill /T` ฆ่าเฉพาะ process ของ Edge ที่สคริปต์เปิดเอง

**ข้อจำกัด:** Edge ต้องรันนอก sandbox ของ Claude Code
