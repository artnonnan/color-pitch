# 02 · บอกสาเหตุจริงเมื่อเปิดไมค์ไม่ได้

## ปัญหา
ผู้ใช้เห็นข้อความ "ไม่ได้รับอนุญาตให้ใช้ไมค์ เปิดได้ที่การตั้งค่าเว็บไซต์ของเบราว์เซอร์" ทั้งที่สาเหตุอาจไม่ใช่เรื่องสิทธิ์
เดิมโค้ดแสดงข้อความนี้กับ **ทุก error** ของไมค์ (ไม่มีไมค์, ไมค์ถูกแอปอื่นใช้, ระบบปฏิบัติการบล็อก, เปิดใน LINE ฯลฯ)

## แก้อะไร
- `lib/pitch.ts`: แยกสาเหตุเป็น 8 แบบ: denied, system-denied, in-app, insecure, unsupported, not-found, in-use, failed
  - ตรวจว่าเปิดในเบราว์เซอร์ของแอป (LINE, Facebook, IG, Messenger, TikTok) ซึ่งมักใช้ไมค์ไม่ได้
  - ถ้าเครื่องไม่รับค่าตั้งเสียง (OverconstrainedError) จะลองใหม่ด้วย `{ audio: true }`
- `components/MicErrorBox.tsx`: กล่องแสดงสาเหตุ วิธีแก้ทีละอุปกรณ์ ปุ่มลองใหม่ และชื่อ error จริง (ซ่อนไว้ในรายละเอียด)
- ใช้กล่องนี้ทั้งในหน้าโน้ตแรกของวันและจูนเนอร์ ข้อความอยู่ใน `i18n/th.ts` → `mic.errors`

## ตรวจแล้ว (Edge headless 375px)
- ปฏิเสธไมค์: ขึ้น "เบราว์เซอร์ถูกตั้งให้บล็อกไมค์ของเว็บนี้" + วิธีแก้ + `NotAllowedError: Permission denied` แล้วใช้แถบเลือกเสียงต่อได้
- อนุญาตไมค์ (C4 ปลอม): วัดได้ 0.03 เซนต์, จูนเนอร์ตอบ C, ปลดล็อก E ที่ข้อ 30, รีโหลด/ออฟไลน์ยังปกติ
